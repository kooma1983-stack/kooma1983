          📋 댓글 데이터 붙여넣기
          브라우저에서 게시물 페이지를 열고 데이터를 가져오는 방법
          1. 페이지에서 F12 (개발자 도구) → Network 탭 → 필터에서 Fetch/XHR 또는 EventStream 선택
          2. 페이지 새로고침 후, 댓글을 불러오는 요청을 클릭
          3. Response 탭에 나오는 내용을 통째로 복사해서 아래에 붙여넣기 (SSE 원문 그대로도, JSON 배열만도 모두 인식돼요)
